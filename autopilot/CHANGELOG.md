# CHANGELOG — autopilot

单一版本号 `V2.00N`。（早期私有迭代使用内部 vNN 编号——v41=V2.001、v43=V2.002、v44=V2.003、v45=V2.004、v46=V2.005、v47=V2.006、v48=V2.007、v49=V2.008。V2.008 起退役。）

**V2.008** — 实战提炼（20 条任务日志 + 3 条 driver 反思）。自扫清单扩展：红转绿后追问"这缝还锁着别的行为吗"；连续失败 ≥3 次强制停下固化踩坑；同文件新轮次冒烟覆盖既往缝；方案之争/跨 ≥3 源文件提示 codebase-design。无 harness 期望值必须注明独立真值来源，且 ≥1 条护栏期望 ≠ buggy 输出。测试清单纪律：统一入口、新测试同轮登记、烧钱测试分层。外部 review 意见处理：先复现→有效才修→线程贴红绿证据回复。收编实战偏方（日志 shell 整条追加、NOTES 兼作 JOURNAL 回退、Edit 工具替代脚本替换、Windows/MSYS 注记）。B-vs-D 分流矛盾钉死：用户报的 bug 永远走诊断 lane；Gate 0 增设 BROKEN 出口；非 git 仓评审快档明文化。

**V2.007** — 定期反思。每 3 个工程轮，任务收尾后 driver 往中央日志本追加一条 `[反思]`：固定终极目标开头 + 五个基于证据的问题（调用时机/含糊规则/自创偏方/最大差距/其他）。计数容错设计；反思只进日志本，绝不自改。

**V2.006** — 利用率与连续性（六轮真实工程加固）。正身优先：fallback 速记版只留给未安装的 skill，跳过正身 = 记偏差。任务所需外部事实必须走 research 形态（后台代理 + 引文落盘）。执行期 15 秒自扫。同会话延续：全文重读只在会话首轮/compact 后/拿不准时。WORKFLOW-ACTIVE 标记 + 项目 AGENTS.md 常驻钩子，新窗口自动召回 driver。首个动代码轮之前必须已跑 setup。用户政策入法：宁可多花 token 不让人参与——评审与验证永不豁免。

**V2.005** — 三道人话考题实测加固（坏掉的切换按钮/复制时间按钮/模糊项目想法）。中文短句直接触发；症状文本即满足 bug lane 入口；纯理解任务不进 lane；子 skill 只回文档时 inline 代执行并注记；无验证命令的仓自发明 seam 断言 + 冒烟。

**V2.004** — 日志成为收尾动作，不再需要用户提醒：一任务一条（交付/STOP/BLOCKED）写进中央日志本；跨轮任务收尾写一条；无 skill 轮次注明原因。任务与轮次语义写死。

**V2.003** — 中央日志本：一本共享文件（位置由安装者定），五方面条目（经过/为啥用/卡点/漏用自查/结果），只追加，绝不进 skill 包。

**V2.002** — 单次触发全自动：跨轮自举、8 核心 skill 入口条件 + 产物约定（其余走四问模板）、给不会写代码的人的交付门（一句话说明 + 手工清单 + 验证原文）、砍掉 HTML 看板、轻痕迹、自进化门（只提案永不自改）。

**V2.001** — 基线：瘦身版 driver（触发表 + 跨轮接续规则，历史归档，规则细节拆分进 `references/`）。
